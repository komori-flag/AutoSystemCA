AutoSystemCA

开机自动系统 CA 注入模块

使用流程

  1. 把证书放入
    /data/adb/modules/auto_system_ca/certs/
  2. 设备有 openssl：直接重启，开机自动转换并注入
  3. 设备无 openssl：点模块的「执行」按钮完成转换（需先装 openssl，如 Termux pkg install openssl-tool），或放入电脑预转换好的 <hash>.0 文件
  4. 重启后生效（或「执行」后强制停止目标应用）

检查注入是否成功

cat /data/adb/modules/auto_system_ca/last-run.log

logcat -d | grep AutoSystemCA

看到 installed 0f4ed297.0 即成功。

注意事项

  • 只注入 certs/ 目录里的证书；删除文件并重启即自动移除
  • root 能看到证书但 App 不信任：KernelSU 设置里关闭「默认卸载模块」，或为该应用设置「保留模块挂载」，再重启应用
  • Android 14+ 需要较新的 KernelSU 版本以支持 /apex 覆盖
